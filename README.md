# VitaCraftika — сайт (RU/EN)
Статический сайт: HTML + CSS + JS, без сборки и без сервера.

## Посмотреть на своём ПК
Распакуй архив и дважды нажми `index.html`.

## Что где менять
- `config.js` — IP сервера, Telegram, ссылка на добровольный донат (`donateUrl`).
- `news.js` — новости (добавляй записи вверх списка).
- `index.html` — правила (блок `rules-list`), тексты на русском. Английский — в `script.js`.
- Моды: положи `.jar` в папку `mods/`, дважды нажми `UPDATE_MODS.bat` (Windows). Он соберёт `mods/mods.zip` и обновит список модов на сайте.

## Публикация (самый лёгкий способ — GitHub Pages)
1. Создай репозиторий на github.com, загрузи в него содержимое папки.
2. Settings → Pages → Branch: main, папка `/ (root)`.
3. Для домена vitacraftika.ru: файл `CNAME` уже лежит в проекте. У регистратора домена добавь записи A на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME для `www` на `<твой-ник>.github.io`. Затем включи Enforce HTTPS.
Подойдёт и любой обычный хостинг: загрузи все файлы в корень сайта.

## Онлайн сервера
Берётся с api.mcsrvstat.us по IP из `config.js` и обновляется раз в 30 секунд. Нужен интернет у посетителя.
Профиль по нику хранится только в браузере посетителя: настоящей базы игроков и регистрации на статическом сайте нет.

## Карта мира
Поставь на сервер BlueMap или Dynmap (есть версии для NeoForge), открой его порт и впиши адрес в `config.js` → `mapUrl`. Если сайт на https, адрес карты тоже должен быть https.

## Статистика игроков
Дважды нажми `UPDATE_STATS.bat` на компьютере с сервером, укажи папку сервера. Скрипт прочитает `world/stats` и обновит `stats.js` (топ-10 по времени игры). Загрузи новый `stats.js` на хостинг.

## v4: главная-сцена
Главная — картинка с дирижаблем и островом. Точки на ней открывают разделы (панели) плавной анимацией. Позиции точек — массив `HS` в `scene.js` (x и y в процентах картинки). Стили сцены и скруглений — `scene.css`.
Онлайн: плашка на картинке и раздел «Онлайн» обновляются каждые 20 с (mcsrvstat.us, запасной — mcstatus.io). Для списка ников включи `enable-query=true` в server.properties.
Карта: впиши https-адрес BlueMap/Dynmap в `config.js` → `mapUrl`, и раздел «Карта мира» заработает.
`window.VC.demo = true` показывает выдуманный онлайн — только для проверки внешнего вида.

## v5: видео-главная
Фон главной — `assets/airship.mp4` (+ `airship.webm`, постер `airship-poster.jpg`). Чтобы заменить видео, подмени эти файлы (без звука, 10–15 с, лучше зацикленное).
Точки стоят на частях дирижабля: массив `HS` в `scene.js` (x и y — проценты кадра видео, d и m — сторона подписи на компьютере и телефоне). Видео и точки считаются одной формулой в `layout()`, поэтому всегда совпадают. Видео 2560x1440, ровный кусок полёта, зациклено.
Кнопка «Как зайти» и IP на главной берутся из `config.js`.
