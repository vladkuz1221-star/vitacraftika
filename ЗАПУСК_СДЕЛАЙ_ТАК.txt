КАК ВЫЛОЖИТЬ САЙТ В ИНТЕРНЕТ (один раз, ~15 минут)

Проверить у себя: дважды нажми index.html. Откроется в браузере.

ВЫЛОЖИТЬ, чтобы видели все:

1. Зайди на github.com, зарегистрируйся (бесплатно).
2. Справа сверху: «+» -> New repository. Название любое, например vitacraftika. Поставь Public. Нажми Create repository.
3. На открывшейся странице нажми ссылку «uploading an existing file».
4. Открой эту папку на компьютере, выдели ВСЁ внутри неё (Ctrl+A, включая папки assets и mods и скрытые файлы) и перетащи в окно браузера. Подожди загрузки, внизу нажми Commit changes.
5. Settings -> Pages. В «Branch» выбери main и «/ (root)», нажми Save.
6. Через 1-2 минуты сайт заработает по адресу ТВОЙ-НИК.github.io/vitacraftika

АДРЕС САЙТА: бесплатный от GitHub (ваш-ник.github.io/vitacraftika). Домен покупать не нужно.

ЧТОБЫ САЙТ НАХОДИЛИ В ПОИСКЕ (сайт уже подготовлен: карта сайта, описание, картинка для ссылок):

9. Яндекс: webmaster.yandex.ru -> Добавить сайт https://ВАШ-НИК.github.io/vitacraftika -> подтверди владение. Самый простой способ: выбери «метатег», Яндекс покажет строку с кодом. Открой index.html блокнотом, найди закомментированную строку yandex-verification, убери вокруг неё <!-- и -->, вставь свой код вместо КОД_ЯНДЕКСА, загрузи index.html на GitHub заново (Add file -> Upload files) и нажми «Проверить».
   Потом в разделе «Индексирование -> Файлы Sitemap» добавь https://ВАШ-НИК.github.io/vitacraftika/sitemap.xml
10. Google: search.google.com/search-console -> то же самое (метатег google-site-verification) + добавь sitemap.xml.
11. Разошли ссылку: в Telegram, в мониторингах и каталогах серверов Minecraft, в описаниях видео.

ЧТО ПОДСТАВИТЬ ПЕРЕД ЗАПУСКОМ (файл config.js, открывается блокнотом):
- ip, telegram — проверь, что верные.
- mapUrl — ссылка на карту BlueMap/Dynmap (https://...). Пока пусто, в разделе «Карта мира» будет заглушка.
- donateUrl — ссылка на донат (можно оставить пустой).
